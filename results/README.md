# Results

Each `YYYYMMDD-HHMMSS-<tag>/` directory is one sweep of the latent-adoption ABM.

> **STATUS: model output, not empirical evidence.**
> Everything here is generated by the simulation. Nothing has been validated against an empirical record, and no claim in the manuscript is presented as one. Every run is seeded and reproducible.

**Read `../../PROJECT_LOG.md` first.** It carries the run history, which sweeps are canonical, which are superseded, and what each established.

## Two canon-selection traps

`audit_docx_fidelity.py` defaults to an old 30-replication canon and reports false failures unless run with:

```
ABM_CANON_DIR="$PWD/results/20260730-093338-full" \
ABM_WEDGE_DIR="$PWD/results/20260730-093438-wedge-explore" \
python audit_docx_fidelity.py
```

Endpoint measurements only reproduce the canon under `w.run()` semantics, which stops at quiescence at a mean tick of about 366. Stepping to a fixed `t=1000` lands mid-sawtooth on the recurring trigger and gives different numbers.

## Per directory

- `LOG.md` — what was run and what it showed (start here for the newer sweeps)
- `REPORT.md` — human-readable report (older sweep format)
- `*.csv` — aggregate results; `*_raw.csv` holds per-replication values
- `timeseries/` — per-tick traces
- `figures/` — rendered figures
- `metadata.json` — full provenance (params, phases, seeds)

Every value reported in the build document maps to a file and column here through `../../PROVENANCE.md`, and `verify_and_document.py` recomputes all of them and fails on any mismatch.
